# data/base/

**Generated** by the CoH3 importer (`node tools/import-coh3/import.js <faction> [squad …]`): one folder per faction with
`weapon.json`, `ebps.json`, `sbps.json`, `veterancy.json`, `upgrade.json`, `fx.json`. **Never edit these files**: the next
import rewrites them. Put changes in `data/units/<faction>/` (overrides) or in a mod (`mods/`).
